fix: resolve 18 E2E test failures - locator strategy for password field

## Problem
18 e2e tests failed with "strict mode violation: getByLabel(/password/i) resolved to 2 elements"
- The regex /password/i matched BOTH the password input (#login-password) 
  AND the "Show password" button (aria-label="Show password")
- Playwright strict mode requires unique locators

## Root Cause
`getByLabel(/password/i)` was too broad - it matched 2 elements with "password" in their label/aria-label.

## Solution
Replace `getByLabel(/password/i).fill(password)` with `page.locator('#login-password').fill(password)`
- The password input consistently has `id="login-password"` across all login pages
- `page.locator('#login-password')` is a CSS selector that uniquely identifies the element
- This avoids ambiguity with the "Show password" button
